Privacy Policy

Application: Aigen Personal Assistant
Last updated: 9 October 2026

Who uses this application

This is a private application used only by its owner on his own Google account. It has no other users and is not offered to the public.

What Google data it accesses

  • Google Drive: only files and folders that the application itself created (scope drive.file). It stores encrypted backup files there. It cannot see other files in Drive.
  • Google Calendar: the owner's own calendar, to read and manage his own events.

How data is used and stored

Data is used only to provide these functions to the owner. Backups are encrypted before they leave the owner's server. Access tokens are stored only on the owner's server.

Sharing

No data is sold, shared with third parties, or used for advertising. The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
